# Triage 标签

各技能以五个规范化的 triage 角色表述。本文件把角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色（例如“打上 AFK-ready 标签”）时，使用本表对应标签字符串。若本仓库标签词汇不同，只需改“本仓库的标签”一列。
